# ImageOrganizeForWork（PhotoSortX）

たまった写真や画像を、整理・管理するためのデスクトップアプリです。
重複・ピンボケ・似た写真の整理や、AI を使った自動の仕分けを、1つの画面でまとめて行えます。

**最新版: v2.3.0**（2026-04-17）

## できること

左のメニューで、次の画面を切り替えます。

| 画面 | 内容 |
|---|---|
| Home | 進み具合やお知らせの表示 |
| Gallery | 取り込んだ画像の一覧 |
| Duplicates | まったく同じ画像のコピーを見つけて消す |
| Blurry photos | ブレ・ピンボケの写真を見つけて消す |
| Tiny files | サムネイルほどの小さな不要ファイルを消す |
| Similar groups | よく似た写真・連写をまとめて確認する |
| Manual sort | 残す・捨てる・フォルダ分けを手で行う |
| AI organize | AI（CLIP）で、写っている内容ごとに自動で分ける |

- 消した画像は、すぐには消えません。フォルダ内の `_TrashBox` に移し、14日間は残します。
- 動画も、最初の場面をサムネイルとして表示します。

## インストール

1. Python 3.10 以上を入れます。
2. このフォルダで、仮想環境（フォルダ専用の Python 環境）を作って有効にします。
3. 必要なライブラリを入れます。

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### AI を使う場合（任意）

「AI organize」を使うときだけ、追加で入れます。詳しくは `AI_SETUP_GUIDE.md` を見てください。

```
pip install "torch>=2.2" "transformers>=4.37"
```

> 補足: GPU が無くても動きます。初回は AI のモデルをインターネットから取得します。

## 使い方

1. `python main.py` で起動します。
2. 「Import」を押し、「フォルダを選んでフル取込」で写真のフォルダを選びます。
3. 「詳細解析（全件）」を押して、画像を解析します。
4. 左のメニューから、整理したい画面を選びます。

- 2回目からは「差分スキャン」で、追加・削除されたファイルだけを反映できます。
- 解析も「差分解析（未解析のファイルのみ）」で、新しいファイルだけを解析できます。

## フォルダ構成（開発者向け）

```
├─ main.py           起動とメインの画面
├─ src/              中心の処理（設定・データベース・スキャンと解析）
├─ gui/              画面の部品（一覧・サムネイル・起動画面など）
├─ modules/          各画面（重複・ピンボケ・似た写真・仕分け・AI など）
├─ tests/            自動テスト（python tests/run_tests.py）
├─ fonts/            画面の文字の形（フォント）
├─ app/              Tauri 版へ移行中の新しい画面（作業途中）
├─ pyproject.toml    パッケージの設定と版（version）
└─ requirements.txt  必要なライブラリ
```

> 補足: 版を上げるときは、`pyproject.toml` の `version` を書き換えます。

## プライバシー

- 写真の情報は、起動したフォルダの `photos.db` に保存します。どこにも送りません。
- AI を使うときも、写真はこのパソコンの中で処理します（初回のモデル取得だけインターネットを使います）。

## 注意

> ⚠️ このリポジトリは公開設定です。

- ログ（`debug.log`）は、最初の設定では詳しい内容まで記録します。ふだん使いでは `src/config.py` の `LOG_LEVEL` を `INFO` にしてください。
- `app/` の Tauri 版は作業の途中で、まだ使えません。
